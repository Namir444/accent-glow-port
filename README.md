### ✨ Accent Glow Portfolio

A modern, visually focused **developer portfolio website** built with a contemporary frontend stack. The project focuses on creating a polished personal web presence with clean UI, responsive design, and an accent-glow visual style.

**Highlights:**

* 🎨 Modern, visually polished portfolio interface
* ✨ Accent-glow inspired UI design
* 📱 Responsive frontend experience
* ⚡ Vite-powered development workflow
* 🧩 Component-based frontend architecture
* 📝 TypeScript-based development
* 🧹 ESLint & Prettier configured for maintainable code
* 🚀 Bun-powered dependency and development workflow

**Tech:** `TypeScript` `Vite` `Bun` `Frontend Development` `Responsive UI` `ESLint` `Prettier`
